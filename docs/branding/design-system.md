# Sistema visual — primera etapa

Referencia inspeccionada: `IDENTIDAD GENERAL.jpg`. Incluye isotipo y logotipo angulares blancos, paleta escrita, recursos de interfaz técnica y composiciones industriales. No especifica fuentes, reglas de espaciado ni archivos independientes de logo.

| Token | Valor | Uso |
| --- | --- | --- |
| `--bg` | `#090909` | Negro de fondo |
| `--gray` | `#5E6672` | Gris frío de apoyo |
| `--petrol` | `#21435E` | Bloques azul petróleo |
| `--accent` | `#136ACF` | Azul interfaz |
| `--text` | `#ECECEC` | Texto principal |
| `--muted` | `#A6ADB8` | Derivado para texto secundario legible |
| `--accent-text` | `#70B2FF` | Derivado para texto azul legible |
| `--surface` | `#101419` | Superficie derivada |
| `--line` | `#303740` | Separador derivado |

Se priorizan los HEX escritos: algunas muestras del JPG difieren visualmente de sus valores. Los derivados son decisiones funcionales de esta implementación, no colores oficiales nuevos.

Arial/Helvetica y Courier New de sistema son **provisionales**: no se identificó la tipografía oficial. El nombre DE155 se presenta en texto editorial; no se recrea el logo. La lámina se conserva como documentación y no se usa como fotografía.

Composición asimétrica, tipografía amplia, índices monoespaciados, bordes finos y acentos azules. Sólo HTML/CSS: sin SVG, Canvas, WebGL, imágenes externas ni generadas. Gutter fluido 1.25–5rem y secciones en una columna móvil/dos escritorio. Focus visible, navegación semántica, enlace de salto y transiciones reducidas según preferencias. Impresión sobre blanco, con azul petróleo en títulos.
